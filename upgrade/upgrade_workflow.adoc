= Atualizar fluxo de trabalho
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Cada versão do SnapCenter contém um servidor SnapCenter atualizado e um pacote de plug-ins. As atualizações do pacote de plug-in são distribuídas com o instalador do SnapCenter. Você pode configurar o SnapCenter para verificar se há atualizações disponíveis.

O fluxo de trabalho mostra as diferentes tarefas necessárias para atualizar o servidor SnapCenter e os pacotes Plug-in.

[NOTE]
====
* O SnapCenter suporta atualizações diretas apenas pelos caminhos mostrados na tabela acima. Se você precisar atualizar para uma versão que não seja diretamente suportada a partir da sua versão atual, você deve realizar uma série de atualizações incrementais. Por exemplo, se você estiver na versão 4.3.x do SnapCenter e quiser atualizar para a 4.6.x, primeiro deve atualizar para a 4.5.x e, em seguida, realizar uma atualização progressiva para a 4.6.x. Essa abordagem garante a compatibilidade entre as versões e evita problemas que podem ocorrer ao pular versões intermediárias. Sempre verifique o caminho de atualização suportado na tabela antes de iniciar sua atualização.
* Para obter informações sobre como atualizar o SnapCenter Plug-in para VMware vSphere, consulte link:https://docs.netapp.com/us-en/sc-plugin-vmware-vsphere/scpivs44_upgrade.html["Atualize o plug-in do SnapCenter para o VMware vSphere"^]
